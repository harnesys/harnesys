Every webhook is a trigger instance bound to a thread and exposed on a public endpoint with a generated token: the endpoint is a secret, rotate the URL if it leaks. curl example: curl -X POST -H 'Content-Type: application/json' -d '{"text": "..."}' https://<host>/addons/public/<orgId>/harnesys.webhook/r/<token> — the fast path reads the top-level .text field; use the text path or template fields for other payloads. With HMAC verification the sender signs the exact raw body and sends it in the signature header, for example X-Hub-Signature-256: sha256=<hmac-hex>, computed with the webhook secret (shown once on rotate). Noise control: a repeated Idempotency-Key header within 24h replays the stored result, identical payloads inside the dedupe window are not re-fired, and requests inside the throttle window get 429. GET fires only when enabled, with the task text in ?text=.... A busy thread reports queued-behind-active-run, a paused instance reports paused, and every request is recorded in recent deliveries.
