Connect a Google account in the connections section. The poller syncs new mail with the Gmail history API using a historyId watermark per account; when Gmail expires the watermark it falls back to a full search with the configured query and resets the watermark. Trigger instances match messages with the Gmail search query and required labels server-side; exclude terms are checked in the add-on. On the first sync of an account only the watermark is stored and existing mail stays silent.
