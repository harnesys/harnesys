## Ограничения по стилю кода (из AGENTS.md)

- Файлы `kebab-case`, нет экспорта по умолчанию (`noDefaultExport: error`).
- Целевой размер файла ~300 строк, жесткий лимит Biome 350 (`noExcessiveLinesPerFile`).
- Объекты — только `interface`; `type` — для алгебр и алиасов (`useConsistentTypeDefinitions`).
- Нет `enum` — только `z.enum` или union-типы (`noEnum: error`).
- Нет комментариев в коде, нет `any`, нет non-null assertion, нет `console` (логгер `Logger`/Pino, не `console`).
- `import type` там, где возможно; `export type` обязательно (`useExportType: error`).
- Директивы DI (токены) никогда не импортируются через `import type`.
