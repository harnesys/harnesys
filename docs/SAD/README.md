# System Architecture Document (SAD)

Harnesys — платформа управления парком агентов и средой выполнения (harness fleet control plane). Данный раздел содержит системную архитектурную документацию (SAD) и техническое описание проектирования (TDD), составленное исключительно на основе исходного кода текущей ветки `main`.

## Назначение документа

Документ предназначен для формирования чёткой и актуальной картины текущего состояния всей системы: всех подсистем, ключевых механизмов, слоёв архитектуры, потоков данных и точек интеграции. Документация составлена строго по коду репозитория; допущения и домыслы отсутствуют. Там где поведение не установлено кодом, это явно указано.

## Как пользоваться

Главная страница — этот файл. Каждый раздел содержит ссылки на смежные разделы. Для детального изучения ключевого механизма начните с раздела 50, а для понимания общей структуры — с разделов 00–04. Для детального изучения пакетов — разделы 52–56, для серверного рантайма — разделы 57–60, для клиентов — разделы 61–64.
