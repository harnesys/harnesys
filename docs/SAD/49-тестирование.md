# 49. Тестирование

## Раннер

Тесты запускаются только через `bun test` (`bun run test`). Только unit-тесты.

## Запреты (жёсткие)

- e2e тесты запрещены.
- RTL (React Testing Library) запрещено.
- playwright запрещено.
- Тесты через HTTP запрещены.
- Тесты через файлы запрещены.
- Охота за покрытием (chasing coverage) не ведётся.

## Расположение тестов

Тесты размещаются рядом с исходным кодом как `*.spec.ts`. Тестируется только чистая логика:
- policy math (бюджет шагов/токенов/дедлайна),
- журнал идемпотентности,
- ценообразование (pricing),
- ограждение (fencing),
- круг secret roundtrip,
- in-memory sqlite.
