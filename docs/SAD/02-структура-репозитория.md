# 02. Структура репозитория

Репозиторий `Harnesys` — монорепо с workspace `workspaces: packages/*, apps/*`, `type: module` — `package.json` корня.

## Корень репозитория

| Путь | Назначение | Источник |
|------|------------|----------|
| `apps/server` | Бэкенд сервер (Hono + Drizzle + brix) | `apps/server/package.json` |
| `apps/webui` | Веб-интерфейс (Vite + React 19) | `apps/webui/package.json` |
| `apps/cli` | CLI инструмент (Bun) | `apps/cli/package.json` |
| `apps/desktop` | Десктоп приложение (Tauri + Rust) | `apps/desktop/package.json` |
| `packages/brix` | DI контейнер и инфраструктура сервера | `packages/brix/package.json` |
| `packages/contracts` | Общие Zod-схемы и типы | `packages/contracts/package.json` |
| `packages/harnesys` | Ядро выполнения агентов | `packages/harnesys/package.json` |
| `packages/integration-telegram` | Интеграция Telegram | `packages/integration-telegram/package.json` |
| `packages/studio-shared` | Общие типы сервера и webui | `packages/studio-shared/package.json` |
| `docs/` | Документация (в т.ч. `docs/SAD`, `docs/addons`, `docs/BUGS`) | репозиторий |
| `deploy/` | Docker-конфигурация, Dokploy | репозиторий |
| `build/` | Собранные бинарники (`harnesys-host`, `assets`) | репозиторий |
| `scripts/` | Сборка, релиз, dev-скрипты | репозиторий |
| `keys/` | Криптографические ключи (приватный, публичные) | репозиторий |
| `landing/` | Лендинг-страница | репозиторий |
| `logs/` | Логи приложения | репозиторий |
| `temp/` | Временные файлы (не трогать без точного имени файла) | AGENTS.md |

## apps/server/src

```
src/
  main.ts                      # точка входа: loadConfig -> AppModule.forRoot -> buildHono -> Bun.serve
  config.schema.ts             # Zod схема конфигурации приложения (AppConfigSchema)
  const.ts                     # константы, версии, пути, безопасные имена
  config/application.yml       # конфигурация YAML с подстановкой env
  app/
    app.module.ts              # корневой модуль AppModule (forRoot -> ApiModule)
    api/                       # REST API слой
      api.module.ts            # регистрация всех модулей и контроллеров, APP_GUARD
      guards/                  # SessionGuard (APP_GUARD)
      rest/                    # 68 файлов *.controller.ts (один ресурс = один файл)
    application/               # слой вариантов использования (38 доменных директорий)
      <домен>/                 # use-case модули (*.use-case.module.ts, *.use-case.ts)
    domain/                    # доменный слой (41 директория доменов)
      <домен>/                 # сущности, порты (*-port.ts), ошибки (*.error.ts)
    infra/                     # инфраструктурный слой (адаптеры, модули)
      <способность>/           # адаптеры (*.adapter.ts), модули (*.module.ts)
    libs/
      trace.ts                 # трассировка
```

## apps/webui/src

```
src/
  main.tsx                     # точка входа React
  pages/                       # страницы (project, onboarding, settings, sign-in, sign-up, desk, inbox)
  widgets/                     # виджеты (chat-transcript, chat-composer, project-sidebar, agent-inspector и др.)
  features/                    # фичи (manage-*, send-message, onboarding, preset-marketplace и др.)
  shared/                      # shared/api (API клиенты), shared/lib, shared/ui, shared/services
  integrations/                # реестр интеграций и клиент Telegram
  entities/                    # сущности домена frontend
```

## packages/brix/src

| Директория | Назначение |
|------------|------------|
| `di/` | контейнер, модуль, инъекции, декораторы, инъектируемость, граф модулей |
| `config/` | загрузка конфигурации, сервер-биндинг, логирование-биндинг |
| `http/` | контекст, контроллер, middleware, маршруты, параметры, Hono-адаптер |
| `errors/` | `ErrorResponse` контракт, `DomainException`, `HttpException`, ошибка-фильтр |
| `guards/` | `CanActivate`, декораторы стражей (`@Public`, `@UseGuards`, `APP_GUARD`) |
| `logging/` | `Logger`, формат лога, ротация файла |
| `metrics/` | метрики HTTP-запросов |
| `health/` | проверка здоровья (`HEALTH_CHECK`) |
| `openapi/` | OpenAPI документ |
| `validation/` | Zod pipe |

## packages/harnesys/src

Ядро выполнения: `adapters/` (AI LLM, кэш, сообщения, Retry, FS загрузчик скиллов, хранилища событий), `application/` (graph, run-engine, compaction, hooks, skills, packs, plugins, tool-registry), `domain/` (agent-definition, attachment, compaction, errors, events, hook, pack, plan, schedule, skill, snapshot, tool-output), `packs/` (agents, base, core, github, google, image, issues, lsp, manager, mcp, memory, plan, scheduler, shell, telegram, threads, web, webhook), `ports/` (интерфейсы портов для сервера), `integration/` — `packages/harnesys/src/`.

Список пакетов возможностей (`packages/harnesys/src/packs/index.ts`): `agents`, `base` (files, shell), `core`, `github`, `google`, `image`, `issues`, `lsp`, `manager`, `mcp`, `memory` (knowledge, pin, semantic), `plan`, `scheduler`, `telegram`, `threads`, `web`, `webhook`.
