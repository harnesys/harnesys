# 12. Конфигурация

## Источники конфигурации

Конфигурация сервера загружается при старте в `apps/server/src/main.ts:21-29`:

1. Файл `APP_CONFIG_DIR_PATH/application.yml` (`apps/server/src/config/application.yml`), если существует — загружается через `configDir`.
2. Переменные окружения подставляются в YAML через `${VAR:-default}` (`packages/brix/src/config/load-config.ts`, функция `substituteEnvVars`).
3. Встроенный YAML `EMBEDDED_APP_CONFIG_YML` (`apps/server/src/const.ts:10`, импорт `config/application.yml` как текста) — используется через `preloadedConfig`, когда файла конфига нет (`main.ts:25-28`).

Логика выбора (`main.ts:21-29`):

```ts
const configFile = join(APP_CONFIG_DIR_PATH, 'application.yml');
const app = Brix.create(AppModule.forRoot(), {
  config: existsSync(configFile)
    ? { schema: AppConfigSchema, configDir: APP_CONFIG_DIR_PATH }
    : {
        schema: AppConfigSchema,
        preloadedConfig: parseConfigYaml(EMBEDDED_APP_CONFIG_YML, process.env),
      },
});
```

Дополнительно `packages/brix/src/config/load-config.ts` (`loadConfig`) поддерживает наложение overlay `application.<env>.yml` через `deepMerge`, когда передан `env`.

## Схема конфигурации (Zod)

`apps/server/src/config.schema.ts` (`AppConfigSchema`):

```ts
const EmptyableString = z.preprocess((value) => value ?? '', z.string());

export const HarnesysPathsConfigSchema = z.object({
  home: EmptyableString.default(''),
  masterKey: EmptyableString.default(''),
  publicUrl: EmptyableString.default(''),
});

export const GithubAppConfigSchema = z.object({
  appId: EmptyableString.default(''),
  privateKey: EmptyableString.default('').transform(normalizePem),
  clientId: EmptyableString.default(''),
  clientSecret: EmptyableString.default(''),
  webhookSecret: EmptyableString.default(''),
  appSlug: EmptyableString.default(''),
});

function normalizePem(value: string): string {
  return value.replace(/\\n/g, '\n').trim();
}

export const AppConfigSchema = z.object({
  environment: z.string().default('local'),
  app: z.object({
    name: z.string(),
    description: z.string().optional(),
    version: z.string(),
  }),
  harnesys: HarnesysPathsConfigSchema.default({ home: '', masterKey: '', publicUrl: '' }),
  githubApp: GithubAppConfigSchema.default({
    appId: '',
    privateKey: '',
    clientId: '',
    clientSecret: '',
    webhookSecret: '',
    appSlug: '',
  }),
});
export type AppConfig = z.infer<typeof AppConfigSchema>;
```

Поля `AppConfigSchema`:
- `environment` — строка, по умолчанию `'local'`.
- `app.name` — строка (обязательная).
- `app.description` — строка, опциональная.
- `app.version` — строка (обязательная).
- `harnesys.home` — `EmptyableString` (null → `''`), по умолчанию `''`. Путь домашней директории Harnesys.
- `harnesys.masterKey` — `EmptyableString`, по умолчанию `''`. Мастер-ключ шифрования.
- `harnesys.publicUrl` — `EmptyableString`, по умолчанию `''`. Публичный URL сервера.
- `githubApp.appId` — ID GitHub App.
- `githubApp.privateKey` — приватный ключ GitHub App с трансформацией `normalizePem` (замена `\n` на реальные переводы строк, `.trim()`).
- `githubApp.clientId`, `githubApp.clientSecret`, `githubApp.webhookSecret`, `githubApp.appSlug` — OAuth параметры GitHub App.

## application.yml (по коду)

`apps/server/src/config/application.yml`:

```yaml
environment: ${NODE_ENV:-local}

app:
  name: ${APP_NAME:-Harnesys}
  description: ${APP_DESCRIPTION:-Harness fleet control plane}
  version: ${APP_VERSION:-0.1.0}

harnesys:
  home: "${HARNESYS_HOME:-}"
  masterKey: "${HARNESYS_MASTER_KEY:-}"
  publicUrl: "${PUBLIC_URL:-}"

githubApp:
  appId: "${HARNESYS_GITHUB_APP_APP_ID:-}"
  privateKey: "${HARNESYS_GITHUB_APP_PRIVATE_KEY:-}"
  clientId: "${HARNESYS_GITHUB_APP_CLIENT_ID:-}"
  clientSecret: "${HARNESYS_GITHUB_APP_CLIENT_SECRET:-}"
  webhookSecret: "${HARNESYS_GITHUB_APP_WEBHOOK_SECRET:-}"
  appSlug: "${HARNESYS_GITHUB_APP_SLUG:-}"

server:
  host: ${SERVER_HOST:-0.0.0.0}
  port: ${SERVER_PORT:-47474}
  api:
    prefix: api
    version:

logging:
  level: info        # fatal | error | warn | info | debug | trace | silent
  pretty: true       # false в production (JSON lines)
  file:
    path: logs/app.log
    maxSizeBytes: 10485760
    maxFiles: 5
```

Переменные окружения: `NODE_ENV`, `APP_NAME`, `APP_DESCRIPTION`, `APP_VERSION`, `HARNESYS_HOME`, `HARNESYS_MASTER_KEY`, `PUBLIC_URL`, `HARNESYS_GITHUB_APP_APP_ID`, `HARNESYS_GITHUB_APP_PRIVATE_KEY`, `HARNESYS_GITHUB_APP_CLIENT_ID`, `HARNESYS_GITHUB_APP_CLIENT_SECRET`, `HARNESYS_GITHUB_APP_WEBHOOK_SECRET`, `HARNESYS_GITHUB_APP_SLUG`, `SERVER_HOST`, `SERVER_PORT`. Процессные секреты живут в `apps/server/.env` (комментарий в `application.yml:8`).

## Диаграмма: загрузка конфигурации

```mermaid
flowchart TD
    Start[Старт сервера main.ts] --> Check{application.yml существует?}
    Check -->|Да| ConfigDir[configDir: APP_CONFIG_DIR_PATH/application.yml]
    Check -->|Нет| Preloaded[preloadedConfig: EMBEDDED_APP_CONFIG_YML + process.env]
    ConfigDir --> Brix[Brix.create(AppModule.forRoot(), {schema: AppConfigSchema, ...})]
    Preloaded --> Brix
    Brix --> EnvSubst[substituteEnvVars: ${VAR:-default}]
    EnvSubst --> Zod[Валидация Zod AppConfigSchema]
    Zod --> App[AppConfig объект]
```
